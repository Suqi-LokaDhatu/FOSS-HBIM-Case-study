# FOSS-HBIM-Case-study

This repository contains the supplementary resources for the case study.

## Contents

1. **Historical documentation and imagery**  
   Items photographed in the Bristol Archives and related image metadata (released under the rights holder’s conditions), together with field photographs prepared for photogrammetry.  

2. **3D reconstruction and intermediates**  
   Meshroom project files and exported OBJ meshes, along with cleaned meshes produced in Blender.  

3. **HBIM modelling files**  
   FreeCAD parametric source files .fcstd for the four parameterised components, together with the exported IFC deliverables .ifc.  

4. **Scripts and configuration**  
   Python scripts used for semantic enrichment (SE) and IDS validation, together with the associated rule sets. Includes the validation summary HIR_LOIN.html.  

5. **BIMserver access information**  
   Instructions and links for accessing the BIMserver instance used in this study.
