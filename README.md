# FOSS-HBIM-Case-study
case study resource archive 
Historical documentation and imagery
Items photographed in the Bristol Archives and related image metadata (released under the rights holder’s conditions), together with field photographs prepared for photogrammetry.

3D reconstruction and intermediates
The Meshroom project files and exported OBJ meshes, along with cleaned meshes produced in Blender.

HBIM modelling files
FreeCAD parametric source files (.fcstd) for the four parameterised components, together with the exported IFC deliverables (.ifc).

Scripts and configuration
Python scripts used for semantic enrichment (SE) and IDS validation, together with the associated rule sets. Includes the validation summary HIR_LOIN_props_report.html.

BIMserver access information
Instructions and links for accessing the BIMserver instance used in this study.
